# 情绪自检网页应用设计文档

## 1. 项目概述

### 1.1 项目名称
情绪自检助手（MoodCheck）

### 1.2 项目背景
现代生活中，人们常常忽视情绪波动背后的生理和环境因素。本项目旨在通过系统化的自检问题，帮助用户快速识别情绪波动的潜在原因，并提供相应的改善建议。

### 1.3 项目目标
- 帮助用户快速识别异常情绪的可能原因
- 提供针对性的自我调节建议
- 简化自检流程，提高用户体验

## 2. 产品定位

一款简单易用的单页面网页应用，通过结构化的问题流程，帮助用户发现情绪波动的潜在原因，并给出相应建议。采用纯前端实现，数据存储在浏览器本地存储中。

## 3. 功能需求

### 3.1 核心功能

#### 3.1.1 情绪自检流程
- 用户打开网页后，可直接开始自检
- 系统按顺序展示预设的18个自检问题
- 每个问题提供"是/否"两个选项
- **关键流程**：当用户对某个问题回答"是"时，立即显示针对该问题的建议，并结束自检
- 如用户确认"这不是我的问题"，则继续下一问题
- 如用户完成所有问题都未找到原因，则提供综合建议

#### 3.1.2 建议展示
- 针对每个问题，提供相应的具体建议
- 建议内容应简洁明了，易于执行
- 对于涉及医疗的问题，明确标注非医疗建议，建议就医

#### 3.1.3 历史记录
- 使用浏览器的 localStorage 保存用户的自检记录
- 记录包含日期、发现的问题和对应建议
- 用户可查看历史记录，了解自己的情绪变化模式

### 3.2 用户界面

#### 3.2.1 首页区域
- 简洁的欢迎信息
- "开始自检"按钮
- "历史记录"入口

#### 3.2.2 问题区域
- 清晰展示当前问题
- "是/否"选择按钮
- 显示当前进度（如"3/18"）

#### 3.2.3 建议区域
- 显示问题概述
- 提供具体建议
- "应用建议并结束"按钮
- "这不是我的问题，继续检查"按钮

#### 3.2.4 历史记录区域
- 按日期排列的历史自检记录
- 点击可查看详情

## 4. 技术实现

### 4.1 开发环境
- HTML5 + CSS3 + JavaScript
- 不依赖任何外部框架，纯原生实现

### 4.2 数据存储
- 使用浏览器的 localStorage API
- 存储内容：用户自检记录（日期、问题、建议）

### 4.3 代码结构
- 单个 HTML 文件包含所有功能
- 内联 CSS 样式
- 内联 JavaScript 代码
- 问题和建议数据以 JavaScript 对象形式存储

## 5. 项目实施计划

### 5.1 开发阶段
1. **需求确认**（1天）
2. **页面设计**（1-2天）
3. **前端开发**（2-3天）
4. **测试**（1天）
5. **GitHub Pages 发布**（1天）

### 5.2 迭代计划
- **第一版**：实现核心自检流程和建议功能
- **后续版本**：根据用户反馈优化体验，可能增加更多个性化功能

## 6. 预期效果

用户通过简单的自检流程，快速找到情绪波动的可能原因，获得针对性建议，从而改善情绪状态。整个过程简洁高效，增强用户自信和控制感。

## 7. 风险与应对

- **风险**：用户可能对非专业建议产生依赖
- **应对**：明确标注非医疗建议的性质，严重情况建议就医

- **风险**：浏览器本地存储数据可能被清除
- **应对**：提供数据导出功能，提醒用户及时备份重要记录

## 8. 结论

本项目采用简单直接的方法帮助用户进行情绪自检，通过"发现一个问题即提供解决方案"的模式，提高用户体验和效率。单页面应用的形式使得部署和访问都更加便捷，GitHub Pages 的发布方式也确保了可访问性。
